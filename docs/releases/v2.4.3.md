# v2.4.3

Button-number markers on non-Touch boards (issue #12): a small "1" and
"2" with a short edge tick at the far right of the screen, at the
vertical positions of the physical buttons on the T-Display S3's board
edge. The bottom-left hint lines say what each button does; these say
which physical button IS "BTN1" — the guess a first-time user previously
had to make by pressing an unlabeled board.

Drawn by one `drawButtonMarkers()` helper (a no-op on Touch boards, per
the issue) at the end of every button-driven screen: menu, roll entry,
word pages, both verify screens, the raw-entropy view, and the
leave-rolling confirm. The momentary wipe screen skips it. Purely
additive rendering — no state, no input, no logic changes.

Digit mapping was verified on hardware (a Touch board running a
forced-non-touch build — same chassis, same button edge): BTN2/GPIO14 is
the top-right button, BTN1/GPIO0 the bottom-right. Touch boards and the
seed algorithm are unchanged.
