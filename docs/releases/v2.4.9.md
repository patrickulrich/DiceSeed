# v2.4.9

The security model made visible on the device (issue #11), plus one
selection language everywhere. No change to the seed algorithm —
`diceseed_core.h`, the wordlist, and the test vectors are byte-for-byte
identical to v2.0.0, the last release that touched any of them (only
the v2.4.1 directory move has touched the files since, rename only);
the same physical rolls produce the same mnemonic, compat and classic
alike.

## Warnings, aligned with SeedSigner's conventions

DiceSeed adopts SeedSigner's two caution tiers — yellow for advisories,
orange for dire — with their wording where it applies:

- **Before the words ever appear**: a once-per-generation orange-bordered
  gate — "Classified Info!" in the title line, "You must keep your seed
  words private & away from all online devices." plus "No USB cable
  should be attached." Dismissed with a hit-tested "I understand" button
  (button 2 on non-touch boards). This is SeedSigner's own
  DireWarningScreen text, and there is no re-entry after dismissing.
- **While the words are shown**: the word pages carry the orange border
  for their entire duration (SeedSigner's warning-edges convention) —
  the caution stays on screen the whole time the phrase is exposed.
- **Roll entry**: a yellow banner — "USB cable disconnected? Roll on
  battery power." — on both board variants. The threat is physical
  (USB-Serial-JTAG is enabled in silicon), so the reminder lives at the
  start of the sensitive session, not only in the README.
- **Raw entropy view**: a yellow "Privacy Leak: this IS your private
  key." headline with "Never photograph or type into an online device."
  (SeedSigner's literal warning-screen headline), replacing the softer
  red line.
- **A wrong quiz answer**: the "Not quite" screen now carries a red
  border — a wrong word on paper is a security failure, not a quiz
  score; the v2.4.4 summary already lists every missed word number.

## One selection language everywhere

The bold-white selection + momentary green confirm flash introduced on
the roll grid (v2.4.2) now applies to every two-tap cell: the 12/24
word-count menu, the leave-rolling Cancel/Wipe confirm, and the backup
quiz's candidate words. Touch boards only; non-touch screens are
unchanged. The firmware-wide color grammar: **white** = armed/selected,
**green** = committed (flash), **yellow** = caution, **orange** = dire,
**red** = failure.

## Security policy and README

- `SECURITY.md` added: a security-policy template pointing at GitHub's
  private "Report a vulnerability" reporting, with maintainer TODOs for
  enabling it — adoption on the main project is targeted for v2.5.0.
- README restructured around the user manual: a step-by-step
  *Installing DiceSeed* walkthrough (including signature verification),
  developer content moved to `docs/building.md`, and a new *Security*
  section for reporting vulnerabilities.
